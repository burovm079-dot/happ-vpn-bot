# HAPP VPN Bot

Telegram-бот для будущего VPN-сервиса с поддержкой приложения HAPP.

> **Текущий статус:** добавлен стартовый каркас Telegram-бота. VPN-серверы, генерация VLESS-конфигураций, подписки и платежи пока **не настроены**. Бот не выдаёт фиктивные VPN-ссылки.

## Что уже есть

- Команды `/start` и `/help`
- Кнопки с краткой информацией о проекте
- Чтение токена из переменной окружения `BOT_TOKEN`
- Шаблон переменных окружения в `.env.example`

## Запуск

Нужен Python 3.10 или новее.

1. Скачайте репозиторий на компьютер или в Android-среду разработки.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` по образцу `.env.example` и вставьте токен, полученный у BotFather:

   ```env
   BOT_TOKEN=вставьте_сюда_токен
   ```

4. Запустите:

   ```bash
   python bot.py
   ```

Не отправляйте токен в чаты и не добавляйте файл `.env` в GitHub.

## Следующие этапы

1. Выбрать и подготовить VPN-сервер (например, с Xray/VLESS).
2. Настроить безопасное создание и отзыв пользовательских конфигураций.
3. Сформировать ссылку подписки в формате, совместимом с актуальной версией HAPP.
4. Добавить базу пользователей и админ-команды.
5. Развернуть бота и VPN-сервер. GitHub хранит исходный код, но сам по себе не запускает бота.

## Важно о бесплатном размещении

Бесплатные тарифы облачных серверов ограничены и могут менять условия или доступность. Нельзя гарантировать бесплатную работу 24/7, серверы во многих странах или стабильность для большого числа пользователей.
